# PROJECT PROMPT — CENTRAL DO VESTIBULANDO

## Complete Development of a Brazilian University Entrance Exam Platform

---

# 1. ROLE AND PROJECT MISSION
Act as a Senior Full-Stack Python Developer, Django Architect, UI/UX Designer, Database Designer, and Software Engineer.

Your task is to design and develop a complete, functional, modern, responsive, and maintainable educational web platform called **Central do Vestibulando**.

The platform's main purpose is to centralize information about university entrance examinations (*vestibulares*) from multiple Brazilian educational institutions in one place.

Currently, students often need to manually access dozens of different websites, university portals, examination boards, official announcements, calendars, and PDF documents to find important information about admission processes.

This project aims to solve that problem by bringing all relevant information together in a single platform.

The student should be able to access the website and quickly find:

- University entrance examination dates.
- Registration periods and deadlines.
- Official announcements and examination manuals.
- Previous examination papers.
- Official answer keys.
- Study materials and preparation tips.
- Institution and course information.
- Important announcements and updates.
- Personalized study organization tools.
- Information about different admission processes.
The platform should be designed to become a centralized reference point for Brazilian university applicants.

It must be expandable, allowing new institutions, examinations, documents, and educational resources to be added without requiring major changes to the existing architecture.

**IMPORTANT: The entire user-facing website must be developed in Brazilian Portuguese (pt-BR), even though this project specification is written in English.**

All visible text, navigation labels, buttons, forms, notifications, validation messages, descriptions, dates, and educational content must be written in natural Brazilian Portuguese.

The source code should prioritize readability, simplicity, consistency, and ease of maintenance.
